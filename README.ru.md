# Mirohodec Warden

**Backend Telegram-бота на Go · Модерация · AI-персонаж Лайя · Mafia · PostgreSQL · Веб-панель**

Это публичная, очищенная версия реального проекта, который, по словам автора, использовался в сообществе и работал на VPS. Бот объединяет инструменты администрирования чатов, социальные механики и игровую платформу. Публичная сборка предназначена для технического просмотра и оценки инженерных решений.

## Что реализовано

| Подсистема | Возможности |
| --- | --- |
| Модерация | Муты, баны, предупреждения со сроками действия, автоматическая эскалация, защита администраторов |
| Несколько чатов | Изолированная конфигурация и состояние супергрупп, отдельные темы и политики |
| Антиспам | Временные окна, счётчики сообщений, ссылок, стикеров, пересылок, повторов, уровни уверенности, страйки и cooldown |
| Лайя | AI-диалоги через внешний API, контекст, индивидуальные настройки персонажа, фильтры ответов, цитаты и FAQ |
| Mafia | Регистрация, комнаты, роли, смена фаз, действия ночью, голосования, ELO, достижения и механики против раскрытия ролей |
| Хранение | JSON и PostgreSQL, SQL-миграции, перенос состояния из JSON в БД |
| Администрирование | Встроенная Go-панель, HTTP API и WebSocket для Mafia Mini App |
| Эксплуатация | Docker, структурированные асинхронные логи, Prometheus, перезагрузка конфигурации, graceful shutdown |

## Быстрый запуск

```bash
cp .env.example .env
cp config.example.yaml config.yaml
# В .env укажите BOT_TOKEN; в config.yaml настройте security.admin_ids.
go mod download
go test ./...
go run ./cmd/warden -config config.yaml
```

По умолчанию используется long polling и JSON-хранилище. AI и веб-панель выключены. Для работы модерации у бота должны быть нужные права в Telegram.

Для Docker:

```bash
cp .env.example .env
# Укажите реальный BOT_TOKEN
docker compose up --build -d
```

## Почему это backend-проект, а не просто Telegram-скрипт

Здесь есть полноценные состояния, длительные бизнес-процессы и несколько способов доступа к системе. У Mafia реализованы игровые переходы и приватная информация игроков, у антиспама независимые сигналы, а у модерации учёт истории наказаний, настроек чатов и существующих ограничений. Разработаны адаптеры хранения и отдельный административный HTTP-сервер.

В публичной переработке длинные Go-файлы разбиты до **200 строк на файл**, локализация и SQL-миграции вынесены в ресурсы. Решения по эскалации предупреждений и удалению спама выделены в чистые доменные функции с тестами. Это **не полная миграция к Clean Architecture**: значительная часть исходной логики остаётся в пакете `cmd/warden`, и этот архитектурный долг обозначен явно.

## Что исключено

Секреты Telegram/OpenRouter, приватная конфигурация VPS, история `.git`, данные пользователей, личные фотографии, логи и резервные копии. React-клиент Mafia Mini App не включён, так как это showcase backend. Его Go API и WebSocket-сервер остались в репозитории.

**Важно:** исходный архив содержал API-ключи, поэтому их необходимо перевыпустить перед публикацией. Полную проверку `go test ./...` нужно выполнить после загрузки зависимостей: в среде подготовки внешние Go-модули недоступны. Тесты независимых доменных модулей выполнены.
